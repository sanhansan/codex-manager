支持与限制

  • mermaid 子集：flowchart TD / LR；节点 A[矩形] A{菱形} A(圆角)；连线 --> / -.-> 与标签 -->|文字|；subgraph 分组
  • 标签后缀随 mermaid/JSON/Markdown 携带：⚙IF（八类门）、▸→工作流名（子流程）、◈agent（节点类型：input / agent / map / cond / merge / output）
  • 「＋新建流程框架」一键生成 输入 → Agent → 条件（是/否）→ 合并 → 输出 骨架，含虚线反馈修正环；工具栏六个「＋类型」按钮可随时加节点
  • 连线：从圆点拖到另一节点新建；拖动连线端点到别的节点 = 改接；红色边 = 反馈环，平行边自动分道；「✨ 一键整理」去重连线并重新排版
  • 节点就地编辑：双击节点直接改标签（或选中后按 F2），Enter / 点空白提交，Esc 取消；节点说明（STEP 文档）在右侧属性面板编辑，随 Markdown「节点说明」与 JSON 导出
  • 底部三个页签与画布双向同步：Mermaid 源码、Markdown 工作流文档、JSON（机器可读，类型/门/子流程完整保留）
  • 左侧任务栏六个视图：画布 / 分布工作区 / 总控流程 / Agent Skills / 轨迹查询 / 问答；工作流列表点击即切换
  • 「🧩 Agent Skills」与「📜 轨迹查询」是独立模块：选 usage.jsonl 后可看每技能调用统计，也可按关键字/类型/会话回放每次调用轨迹；Skill 工坊还能从问答/提示词或习惯候选生成 SKILL.md，导出或一键安装给智能体调用
  • 「🛠 Skill 工坊」把习惯候选自动扩写成 SKILL.md 草稿（英中双关键词），可编辑后保存到草稿目录（~/.zcode/codex-manager/skills）或直接安装到插件 skills/；「🔄 刷新已保存列表」可载回继续编辑
  • 「💬 问答」回放三家客户端（ZCode / Codex CLI / Qoder CLI）的会话问答：HTTP 托管时自动同步最新会话 + 全部子智能体（每条带客户端色徽章），file:// 下可选 rollout 会话文件与子智能体目录；「⚡ 一键重点与提示词」自动打分提炼重点，「🖼 生成工作画布」按 🧠 总任务 / 🤖 子智能体生成画布；徽章区分 🧠 总智能体（主会话，与画布同源的标「画布来源」）与 🤖 子智能体，每条可「→ 添加为画布节点」或「→ 查看 X 用量」转跳 Token 区块
  • AI 助手两条提示词通道：「优化连线」（只调结构：汇合/分支/反馈）与「优化整个流程」；校验会检查环路、类型规则（输入无入边、条件两分支等）、门规则与可达性
  • 超过 8 层的线性链自动蛇形折行；重复连线与自环会被拒绝
  • 「🔗 连接文件」后画布与本地文件双向同步：AI / 会话改文件 → 画布自动更新；画布改动 → 自动写回文件（建议 Edge / Chrome）；用 flow_serve.py 托管时打开即自动连接，零点击
  • 🌐 语言按钮随时切换中文 / English（记住选择）；「📦 使用量」「🪙 Token 使用量（多客户端）」在总控流程视图，flow_serve.py 托管时自动载入——Token 按日/按月切换、悬停看各客户端分解、点数据点出周期明细并可「→ 查看问答」；文件服务断开时每 4 秒自动重连

    • 文本是唯一事实源。导出后可在会话里用 /codex-flow-save 回写项目框架；JSON 最完整，Markdown 适合人读与版本库。
