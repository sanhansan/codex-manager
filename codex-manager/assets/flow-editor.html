支持与限制

  • mermaid 子集：flowchart TD / LR；节点 A[矩形] A{菱形} A(圆角)；连线 --> / -.-> 与标签 -->|文字|；subgraph 分组
  • 逻辑门与子流程用标签后缀随 mermaid 携带：⚙IF（八类门）、▸→工作流名（子流程）
  • 底部三个页签与画布双向同步：Mermaid 源码、Markdown 工作流文档、JSON（机器可读，门/子流程完整保留）
  • 左侧任务栏：画布 / 分布工作区 / 总控流程 三个视图手动切换；工作流列表点击即切换
  • 「🛰 分布工作区」：每个工作流是一张卡片（打开 / 重命名 / 删除 / 导出）
  • 「🧭 总控流程」：关系图 + 关系表，展示所有工作流与子流程引用
  • 超过 8 层的线性链自动蛇形折行；重复连线与自环会被拒绝
  • 「🔗 连接文件」后画布与本地文件双向同步：AI / 会话改文件 → 画布自动更新；画布改动 → 自动写回文件（建议 Edge / Chrome）
  • 「📊 习惯与技能」页：选择 usage.jsonl 即可看技能总结、调用排行、活跃趋势与习惯候选，可复制 Markdown 总结

    • 文本是唯一事实源。导出后可在会话里用 /codex-flow-save 回写项目框架；JSON 最完整，Markdown 适合人读与版本库。
